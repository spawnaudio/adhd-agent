# Focus — macOS v1

Status: user directed implementation of a standalone macOS app with pasted Linear tasks. Supersedes the Safari extension proposal.

## Purpose

Keep one intended task and a small next action visible. Let the user deliberately pause focus and save distracting ideas for later. Use calm language without scores or guilt.

## Scope

- Native macOS app, plus menu-bar access.
- Paste a Linear issue URL, copied issue text, or ordinary task text.
- Enter one next action and start focus.
- Open a pasted HTTPS Linear issue link; no fetching issue contents or account connection.
- Explicit pause confirmation with a 5, 10, or 15 minute break.
- Restore focus and bring the existing window forward when the break expires while the app runs.
- Reconcile pause expiry after sleep and reopening the app.
- Save ideas locally and review/delete them later.
- End a session while keeping its task and saved ideas.

## Implementation decisions

SwiftUI app with a separate Foundation session model, built with Swift Package Manager and bundled as a local .app. No dependencies or cloud service. Session state uses local UserDefaults. This is a deterministic app foundation; an AI agent is a later feature, with provider and behavior to be agreed then.

## Limits

No Safari extension, browsing interception, app blocking, screen monitoring, notifications while the app is quit, Linear API, or automatic task interpretation. Pausing is user initiated. Local data is not encrypted by the app. Closing the window keeps menu-bar access; quitting stops the running app.

## Validation

Build the native executable and app bundle. Test empty input, Linear URL extraction, pause persistence/expiry, and retention of task/ideas when ending a session. Document any unverified graphical behavior. Manually verify launch, paste/start, saving an idea, timed pause/resume, quit/relaunch, sleep/wake, and menu-bar access on the Mac.

## Later

Consider AI assistance for selecting a small next action and live Linear task selection after trying this focus loop. Do not add an extension without a new request.
